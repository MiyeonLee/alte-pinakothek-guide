# Alte Pinakothek Korean Docent Web App (알테 피나코텍 한글 도슨트 웹앱)

뮌헨 알테 피나코텍(Alte Pinakothek)에 현재 전시 중인 작품 목록과 전시실 위치(`Saal`, `Kabinett`)를 바이에른 주립 회화 컬렉션 공식 데이터베이스(`sammlung.pinakothek.de`)에서 수집하고, 주요 대표작의 한글 도슨트 해설과 개인 관람 편의 기능을 제공하는 모바일 최적화 PWA(Progressive Web App)입니다.

---

## 주요 기능

* **실시간 전시 배치 및 소장처 구분:**
  * 공식 컬렉션 검색 API(`/api/search`)를 통해 현재 알테 피나코텍(`AP`) 내부(`1층 OG`, `지하층 EG`, 입구홀)에 전시 중인 작품을 수집합니다.
  * 상설 소장품(**알테 피나코테크 14~18세기**)과 지하층 특별 전시 중인 **노이 피나코테크(NP) 임시전시 19세기 근대 명화**를 배지와 드롭다운 필터로 구분해 탐색할 수 있습니다.
* **전시실 빠른 탐색 및 현장 내비게이션:**
  * 층별(`1층 OG` / `지하층 EG`), 전시실별(`Saal I ~ XIII`, `Kabinett 1-2 ~ 23`), 핵심 걸작 필터, 한글 해설 보유작 필터 및 통합 검색을 지원합니다.
  * **전시실 번호 빠른 점프:** 검색창에 숫자(`7`, `12`)나 로마자(`VII`)를 입력하면 해당 전시실 바로가기 퀵 버튼이 즉시 표시됩니다.
  * **인접 전시실 이동 바:** 특정 전시실 선택 시 상단에 `← 이전 전시실 | 현재 전시실 | 다음 전시실 →` 버튼이 나타나 미술관 동선에 따라 원터치로 이동할 수 있습니다.
* **4개 탭 기반 입체적 미술사 & 관람 동선 가이드:**
  * **작품 목록:** 전시실별 카드 리스트 및 상세 해설 조회
  * **추천 관람 동선:** 여행 일정에 맞춘 **1시간(핵심 압축)**, **2시간(표준 정통)**, **3시간+(심층 및 노이 피나코테크 포함)** 단계별 동선과 구간별 대표작 연결
  * **미술 사조별 해설:** 초기 르네상스부터 세기말 상징주의·초기 모더니즘까지 13개 사조의 특징과 연계 전시작 안내
  * **작가별 개요:** 주요 거장들의 생애·화풍 요약 및 사조별 필터링
* **개인 여행자를 위한 체크리스트 & 오프라인 음성 도슨트:**
  * **위시리스트 & 관람 완료 체크:** `localStorage` 기반으로 보고 싶은 작품을 미리 찜(`☆ 찜`)하고, 현장에서 감상한 작품을 `✓ 완료`로 기록할 수 있습니다.
  * **오프라인 한국어 음성 도슨트(TTS):** 브라우저 내장 Web Speech API(`window.speechSynthesis`)를 활용해 별도 데이터 소모 없이 한국어 음성 해설 재생·일시정지·배속 조절(`1.0x` / `1.2x` / `1.4x`)을 지원합니다.
* **아이폰(iOS Safari) PWA 및 오프라인 지원:**
  * Safari의 **"홈 화면에 추가"** 기능으로 네이티브 앱처럼 전체 화면 실행이 가능하며, `Service Worker`와 `localStorage` 캐싱을 통해 미술관 내부 약전파/오프라인 환경에서도 끊김 없이 작동합니다.

## 아이폰(iOS Safari) 홈 화면 설치 방법

1. 아이폰 Safari에서 배포 주소(`https://miyeonlee.github.io/alte-pinakothek-guide/`)로 접속합니다.
2. 하단 메뉴 막대의 **공유 버튼(네모 위 화살표)**을 누릅니다.
3. **"홈 화면에 추가"**를 선택하고 우측 상단 **"추가"**를 탭합니다.
4. 상단 배지가 `최신 동기화됨`으로 표시되는 것을 한 번 확인하면, 이후 미술관 현장에서 인터넷 연결 없이도 오프라인 앱으로 실행됩니다.
